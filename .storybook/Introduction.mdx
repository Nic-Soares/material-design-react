# Material Design React

React components that implement [Material Design 3](https://m3.material.io),
including M3 Expressive — native elements, accessible by default, themed with
plain CSS variables.

> **Early development.** The package is set up; tokens and components are
> being added. Nothing is published to npm yet.

## Install

```sh
npm install @nic-soares/material-design-react
```

React 19 and React DOM 19 are peer dependencies.

## Use

Import the stylesheet once, at the root of your app, then the components:

```tsx
import "@nic-soares/material-design-react/styles.css";
import { Button } from "@nic-soares/material-design-react";

export function App() {
  return <Button variant="filled">Save</Button>;
}
```

Each component renders its native element and accepts that element's props —
`id`, `className`, `style`, `aria-*`, event handlers — and a `ref`.

## Theme

Components read only the Material Design 3 system tokens, as CSS variables
(`--md-sys-color-*`, `--md-sys-typescale-*`, `--md-sys-shape-*`, …). The
library ships a light and a dark scheme; to use yours, set the same
variables:

```css
:root {
  --md-sys-color-primary: rgb(86 100 34);
  --md-sys-color-on-primary: rgb(255 255 255);
}
```

The library ships light and dark schemes in standard, medium and high
contrast, generated with
[Material Color Utilities](https://github.com/material-foundation/material-color-utilities).
The theme follows the system setting; set `data-theme="light"` or `"dark"` to
pin it — on `<html>` or on any element, for a region in the other theme. Set
`data-contrast="medium"` or `"high"` the same way; high contrast also follows
the system's *Increase contrast* setting.

Use the toolbar above to switch theme, contrast and motion here, and see
every token under **Foundations/Tokens**.

The color tokens use CSS `light-dark()`, so the library needs Chrome or Edge
123, Firefox 120, Safari 17.5 or later.

## Typography

The type scale follows Material Design 3, baseline and emphasized, as
`--md-sys-typescale-*` tokens in `rem`, so text follows the font size set in
the browser. Every style uses one of two typefaces, both Roboto by default:

```css
:root {
  --md-ref-typeface-brand: "Your Display Font", sans-serif; /* display, headline, title large */
  --md-ref-typeface-plain: "Your Text Font", sans-serif; /* everything else */
}
```

The library ships no font files. To use Roboto, load it in your app — for
example, self-hosted with Fontsource:

```sh
npm install @fontsource-variable/roboto
```

```tsx
import "@fontsource-variable/roboto";
```

and point the typefaces at it: `--md-ref-typeface-plain: "Roboto Variable",
sans-serif;` (and the same for brand).

## Shape, elevation and motion

Corners use `--md-sys-shape-corner-*` (none to extra-extra-large, the M3
Expressive *increased* steps and full), shadows `--md-sys-elevation-level0`
to `level5`.

Motion follows M3 Expressive's springs. Each spring is an easing and a
duration, used together:

```css
.card {
  transition: transform var(--md-sys-motion-spring-default-spatial-duration)
    var(--md-sys-motion-spring-default-spatial-easing);
}
```

Spatial springs (position, size) overshoot a little; effects springs (color,
opacity) don't. Set `data-motion="standard"` for the calmer standard springs.

## Icons

Components take icons as React nodes, so you load only the icons you use, in
any format. With [Material Symbols](https://fonts.google.com/icons), the icon
set Material Design recommends:

```tsx
<Button icon={<span className="material-symbols-outlined">add</span>}>
  New
</Button>
```

## Accessibility

Every component handles keyboard, focus, roles and `aria-*` attributes, and
its tests run [axe](https://github.com/dequelabs/axe-core) in light and dark.
The **Accessibility** panel at the bottom of each story runs axe in your
browser, including the contrast checks.
